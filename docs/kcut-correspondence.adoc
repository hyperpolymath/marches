= K-CUT correspondence — a table of names, not a link
:revdate: 2026-10-14

marches (Lean 4, kept as provenance) proves that a region crossing is a
cut (`Marches/Cut.lean`). choreographic-types (Agda, the proof kernel)
proves the cut side of K-CUT for global choreographies. This page pairs
the names. It does not link the proofs: no row is more than ASSUMED, in
the idiom of resource-algebra's M-2 — cross-prover, port-and-reprove, a
named obligation, no mechanical link exists or is claimed.

What IS mechanical: `scripts/check-correspondence.sh` fetches the
siblings at the pins below and checks that every name cited on this page
exists — Lean names in this build, sibling names at their pinned commits —
and that every pin appears here. A fabricated Lean name and a fabricated
Agda name are run through the same checks as a negative control and must
be refused. The script checks names only. Whether two paired names mean
the same thing is falsifier F6 (`FALSIFIERS.adoc`), and one proposed row
below already fails it.

Delimitation: nothing here is a convergence claim; agda-routing owns that
ground (`LIMITATIONS.adoc`).

== Transport, for postern

T-2 (choreographic-types, PROVEN for the synchronous fragment): receiving
is knowing (`choreographic-types:src/Choreographic/Instances.agda:receiver-knows`);
synchronously, so is sending
(`choreographic-types:src/Choreographic/Instances.agda:sender-knows`). Both
instantiate the generic
`choreographic-types:src/Choreographic/Transport.agda:knows-local-cut`.
MRC-01 cited `Transport.agda` for the two named lemmas. At the pin they
are in `Instances.agda`. Under asynchrony, `sender-knows` is expected to
FAIL (PROOF-STATUS, "Open: Asynchrony"). That is OPEN, and it is the
property an ACK-based containment boundary relies on: a sender without
receipt cannot know.
